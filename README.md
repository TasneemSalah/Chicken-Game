# Chicken Game

A 2D Java game built using JOGL (Java OpenGL) as part of a university project. The game demonstrates real-time rendering, animation handling, collision detection, and interactive gameplay mechanics using OpenGL in Java.

## Overview

Chicken Game is an arcade-style game developed to explore computer graphics concepts, game loops, and interactive application development in Java. The project focuses on rendering performance, user interaction, and gameplay logic implementation.

## Features

* Real-time 2D rendering using JOGL
* Keyboard-based player controls
* Collision detection system
* Animation and sprite movement
* Score and game state handling
* Object-oriented game structure
* Interactive gameplay loop

## Technologies Used

* Java
* JOGL (Java OpenGL)
* OpenGL concepts
* Object-Oriented Programming

## How to Run the Project

### Prerequisites

* Java JDK installed
* JOGL libraries configured
* IDE such as IntelliJ IDEA or Eclipse

### Running

1. Clone the repository:

```bash
git clone https://github.com/TasneemSalah/Chicken-Game.git
```

2. Open the project in your preferred Java IDE.

3. Configure JOGL dependencies if required.

4. Run the main application class.
